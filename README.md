# Surya Shree & Vijay Raj Wedding Invitation

Open `index.html` in a current web browser, or serve this folder with any static web server.

The invitation is fully self-contained apart from the optional Google Fonts request. It uses the original multi-section design, with the requested Tamil opening line and without a standalone venue section. The two provided image assets and the location QR crop are kept in `assets/`.

Features included:

- Mobile-first opening invitation screen with the original couple illustration
- Smooth open transition, petal motion, and scroll-reveal details
- Reception and Muhurtham event cards
- Live countdown targeting 20 November 2026, 9:15 A.M. IST
- Map buttons, the original location QR code, and calendar (.ics) download
- Optional tap-to-play ambient wedding chimes (never autoplays)
